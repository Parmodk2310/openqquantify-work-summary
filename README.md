## About OpenQQuantify

## Projects I Contributed To

### 1. Circuit Agent
**Stack:** Python · Flask · Docker · QEMU

A platform enabling communication between a chat-based frontend interface and a QEMU-based Docker environment for circuit simulation.

**My contributions:**
- Debugged and improved existing Flask communication channels between the frontend and backend
- Fixed issues in the request-response pipeline between the chat interface and the QEMU environment
- Worked closely with the CTO to identify and resolve integration bugs

---

### 2. Cesium Signals (3D Geospatial Simulation Platform)
**Stack:** CesiumJS · JavaScript · HTML5 · CSS3

An interactive 3D globe-based platform for geospatial visualization, sensor simulation, and model deployment.

**My contributions:**
- Debugged sensor placement logic and drag-and-drop functionality on the 3D globe interface
- Fixed rendering and entity management issues in the CesiumJS implementation
- Improved simulation control behavior (play, pause, reset flows)
- Worked independently on specific bug fixes; collaborated with the team on integration testing

---

### 3. Multi-Agent LLM Application
**Stack:** Python · LangChain · OpenAI API

A multi-agent reasoning system designed to handle complex, multi-step AI tasks through coordinated agent interactions.

**My contributions:**
- Identified accuracy failures in the multi-agent reasoning pipeline
- Improved prompt structures and agent coordination logic to reduce reasoning errors
- Tested and validated improvements against existing benchmarks
- Collaborated directly with the CEO on evaluating output quality
